# Система расчёта зарплаты - Лабораторная работа №4 (C++ wxWidgets)

## Описание
Десктопное приложение для управления сотрудниками и расчёта зарплаты.
Разработано на C++ с использованием фреймворка wxWidgets.

## Технологии
- C++17
- wxWidgets 3.3.1
- vcpkg (пакетный менеджер)
- Visual Studio 2022

## Функционал
- ✅ Два окна (главное + статистика)
- ✅ Перегрузка конструктора в StatisticsDialog
- ✅ Импорт/экспорт TXT файлов
- ✅ CRUD операции (добавление, редактирование, удаление)
- ✅ Сортировка по зарплате (3 режима)
- ✅ Валидация полей ввода (буквы в имени/фамилии, 0-3млн в зарплате)
- ✅ wxGrid для отображения данных
- ✅ Статистика (базовая ≤3 сотрудников, расширенная >3 сотрудников)
