# Система расчёта зарплаты - Лабораторная работа №4

## Описание
Десктопное приложение для управления сотрудниками и расчёта зарплаты.
Разработано на C# + Windows Forms.

## Технологии
- C# + Windows Forms (.NET Framework 4.7.2)
- Visual Studio 2022

## Функционал
- Два окна (главная форма + форма редактирования)
- Перегрузка конструктора в FormEdit
- Импорт/экспорт CSV (OpenFileDialog, SaveFileDialog)
- CRUD операции (добавление, редактирование, удаление)
- Сортировка по зарплате и имени
- Валидация полей ввода (ErrorProvider)
- DataGridView для отображения данных

## Структура проекта
laba4/
├── FormMain.cs # Главная форма
├── FormEdit.cs # Форма редактирования
├── Employee.cs # Класс сотрудника
├── PayrollSystem.cs # Singleton система
├── SalaryStrategy.cs # Абстрактный класс
├── RegularWork.cs # Обычная работа
├── BonusWork.cs # Работа с надбавкой
├── CompletedWork.cs # Выполненная работа
└── Program.cs # Точка входа
## Как запустить
1. Открыть `PayrollApp.sln` в Visual Studio 2022
2. Нажать `Сборка → Перестроить решение`
3. Нажать `F5` для запуска
